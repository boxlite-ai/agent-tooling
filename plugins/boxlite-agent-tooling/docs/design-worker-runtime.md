## Runtime preparation

The process owner registers one broker through an authenticated loopback channel and owns worker teardown.
Rejected inputs preserve the listener and registration slot; Windows job failures release acquired handles.

A denied registration can be followed by a valid owned broker.
POSIX controllers terminate their own groups; the parent signals only owned child processes.
Native Windows and Linux qualification remains pending.

See the registered [design](https://github.com/boxlite-ai/agent-tooling/issues/354) for the complete gate contract.
