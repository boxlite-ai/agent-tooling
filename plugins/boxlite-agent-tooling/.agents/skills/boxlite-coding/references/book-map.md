# Source and chapter map

Robert C. Martin et al., *Clean Code: A Handbook of Agile Software Craftsmanship*,
first edition, Prentice Hall, first printing 2008, copyright 2009,
ISBN 9780132350884. [Publisher record](https://www.informit.com/store/clean-code-a-handbook-of-agile-software-craftsmanship-9780132350884).
References use printed pages, not PDF page numbers. This skill is original
synthesis, not a substitute for the book or a reproduction of its listings.

The source review covered the complete first edition: front matter, all seventeen
chapters, all appendix listings, epilogue, and index. Selected lessons appear below;
coverage does not imply endorsement of every prescription or verified execution
of the examples. Contemporary adaptations are labeled in the decision guide.
